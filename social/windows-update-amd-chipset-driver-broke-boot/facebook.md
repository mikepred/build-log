# Facebook: Windows Update pushed an AMD chipset driver over mine and broke boot

Draft only. Mike schedules it himself.

Fresh Windows install, did everything "right," installed the drivers from the motherboard maker... then Windows Update swapped in its own AMD driver and the PC wouldn't boot. 😅

Windows' own repair tool figured it out and rolled it back. Now Windows Update isn't allowed to touch my drivers, and the PC saves crash evidence so I'm not guessing next time.

The whole story, plus the steps if you want to do the same: https://mikepred.github.io/build-log/windows-update-amd-chipset-driver-broke-boot/
