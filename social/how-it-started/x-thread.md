# X thread: How it started

Draft only. Mike schedules it himself. Post after the entry is live.

**1/5**
A week ago I opened one Grok Bot and told it: "I don't know what bots I need yet. It will emerge." By the next morning I had seven, each with one job. By the end of the week, nine. Today I deleted all of them. 🧵

**2/5**
Rule one held up the whole week: no new bot without evidence. Same kind of ask, two or three times, then a bot. My PC bot existed because nearly every case was that one PC. The "publisher bot" I wanted turned out to be a GitHub Action.

**3/5**
Every bot got one job and a written list of things it never does. Makers write code, and one checker owns no code and never applies a patch. A second-opinion bot argued with Grok for a second round, and that's where all the value was.

**4/5**
The build log came out of it too: one markdown file per real problem, my merge as the only approval. Not the ten-channel content farm a PRD wanted. "The process of fixing it becomes the content."

**5/5**
Now it's one bot, HQ: my main workbench, and the build log is a byproduct of the work there. Nine bots was the scaffolding. The rules are what I'm keeping. Write-up: https://mikepred.github.io/build-log/how-it-started/
