# Facebook: How it started

Draft only. Mike schedules it himself.

Week one of my AI experiment, start to finish: I started with one assistant, ended up with a team of nine (one for my PC, one to write things up, one to double-check code, one to argue with other AIs...), and today I deleted all of them and went back to one.

Turns out the team was scaffolding. What stuck were a few rules: don't add a helper until you actually need it, give each one exactly one job, and never let the thing that wrote the code be the thing that approves it.

The whole story's here: https://mikepred.github.io/build-log/how-it-started/
