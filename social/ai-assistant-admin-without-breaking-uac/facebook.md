# Facebook: Giving my Grok Bot assistant admin rights without switching off UAC

Draft only. Mike schedules it himself.

Nerdy one. One of my Grok Bot assistants, dr eggbot, helps me set up my PC, but it doesn't have admin rights, so it kept asking me to paste commands for it. The easy fix would have quietly switched off one of Windows' main safety prompts, so we didn't do that.

Instead it gets a short menu of five admin jobs it can start but can't change. I tested it, and it really can't change them. 🔒 Adding anything new to the menu still needs me.

Full write-up: https://mikepred.github.io/build-log/ai-assistant-admin-without-breaking-uac/
