# Facebook: One markdown file, three sites: what broke the first time my crosspost ran

Draft only. Mike schedules it himself.

I set up my build log so I write each post once and it shows up on my site, dev.to and Hashnode automatically. Then I didn't actually use it for a week. 😅

The first real post broke it four different ways: broken image links, a version mismatch in the install step, Hashnode quietly moving its API, and (my favorite) a failure that still showed a green checkmark.

Five small fixes and one late night later, it works. The next post went out everywhere on the first try.

Write-up here: https://mikepred.github.io/build-log/one-markdown-file-three-sites/
