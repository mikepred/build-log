this morning's decision: every agent i use keeps its own private session record in notion. there are 9 matching databases now, one per tool: grok bot, codex, claude code, cursor, github copilot, hermes, claude.ai, chatgpt and perplexity. same columns in all of them. the conversation apps save full transcripts. it all stays private, so none of it shows up here.

rows got a naming rule too. the name is just a short description of the session, like "PR 17 URL rewriting repair". no date and no tool name in it, since the date column and the database already say that.

one relabel: the database i'd been calling "chatgpt" turned out to be all codex sessions, so it's codex now. chatgpt kept a separate database for the cloud app.

claude code and codex joined the PR review flow. with that many reviewers, one comment could set off duplicate runs and get three replies. a lock fixed that, so it's one reply per comment now.

the obsidian vault plan is finally moving: a karpathy-style llm-wiki, hindsight for memory, and qmd for search. hermes is installing it on my PC right now, starting with WSL so docker can run.

side quest: i have notion's education plan on my school account, so i checked whether it could upgrade my personal workspace. it can't. the plan is tied to the school email and one workspace, and it goes away once i can't verify the email. so everything stays on the personal workspace.
